Open Source AI Stack — Reference Architecture

A fully open source software stack for SMBs, running on 1–2 servers, covering everything from the OS to end-user-facing analytics/AI applications — chat + RAG, classification/prediction, SSO, and security. Every component ships under an OSI-approved (or explicitly noted) open source license and runs entirely on-prem.
